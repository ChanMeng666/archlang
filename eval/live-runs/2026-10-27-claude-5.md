# Live eval run, 2026-10-27 — Claude 5.x on the 26-brief corpus

A dated record of one owner-authorised `npm run eval:live -- --yes --l1` run. It is **not** a
baseline and does not replace `eval/live-baseline.json`, which was not re-measured.

## What ran

- Models (provider `anthropic`): `claude-opus-5-5`, `claude-sonnet-5-5`, `claude-haiku-5-5`,
  `claude-fable-5-1`. Each ran the full corpus **once** (n = 26, one run each) with the `--l1`
  overlay and `--budget 900000tok`.
- Judge v2, synonyms v1, rubric v1 (frozen). Code: `main@441f5fc3` plus the temperature fix of
  PR #295.
- Temperature is **unpinned**: the 5.5 models reject the parameter, so none was sent (PR #295). The
  scorecard header still prints `temp 0`; read that as a label, not a setting.
- Date: 2026-10-27. Cost source: the Anthropic Console. There is no per-run dollar figure because
  the harness has no 5.5 prices (`usd n/a`); the token circuit breaker reported 393k–436k tokens per
  model over 26 calls.
- A further partial Opus re-run was aborted and is excluded.

## Failure buckets

Every brief that is not a clean L0 pass was classified from the run notes. Counts per model (rows
sum to 26; the "passes" row is briefs with no failure note, i.e. valid, intent met and no lint
warning):

| Bucket | Opus | Sonnet | Haiku | Fable |
| --- | --- | --- | --- | --- |
| Empty or truncated output | 0 | 0 | 0 | 0 |
| Compile error: invented syntax (`Unknown statement …`) | 2 | 3 | 4 | 7 |
| Compile error: furniture without `size WxH` | 1 | 1 | 1 | 4 |
| Compile error: other (refused opening, unknown room, …) | 1 | 1 | 4 | 2 |
| Compiles, intent miss | 3 | 2 | 1 | 2 |
| Compiles, intent met, fails on a physical lint warning | 1 | 0 | 8 | 3 |
| Compiles, intent met, other lint warnings only | 16 | 16 | 7 | 8 |
| Passes with no note | 2 | 3 | 1 | 0 |

The "intent met, lint warnings only" row is not a failure of validity or intent; it is why sound
is low everywhere.

**Fable's 13/26 valid is not truncation.** All 13 of its invalid briefs are compile errors raised
by the compiler on well-formed output, mostly statements the language does not have
(7) and furniture given no size (4). No note from any model shows empty output or an
end-of-input parse error, so the `max_tokens` 16384 ceiling is not what limits these numbers. The
notes cannot rule out a truncation that happened to end on a clean statement, because the harness
does not record `stop_reason`. The result is a language-surface finding: Fable 5.1 guessed more `.arch`
syntax (statements the language does not have) than the three 5.5 models.

## Caveats

- n = 26, one run per model. Intervals are wide and overlap for most pairs; do not rank models on
  these rows.
- **Not comparable with `eval/live-baseline.json`.** The baseline is another provider and model
  (`gpt-5.5-2026-04-23`), and `spec.llm.md` has drifted since 2026-07-12 (see "Prompt-drift
  history" in `eval/README.md`). The scorecards printed a delta against the baseline; ignore it.
- Temperature unpinned, so a rerun can differ.
- Aggregate numbers only. Per-brief names and texts are holdout material and are deliberately
  absent here.
