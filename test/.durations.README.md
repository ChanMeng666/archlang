`.durations.json` is seconds per test file; `sequencer.ts` balances `vitest --shard` by it.
A stale or missing entry costs shard balance, never correctness (an absent file counts as the median); it is not a drift artifact.
Regenerate: `npx vitest run --reporter=json --outputFile=r.json && node scripts/gen-test-durations.mjs r.json` (nightly uploads one as the `test-durations` artifact).
