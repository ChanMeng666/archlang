# Regenerate generated artifacts

Run every single-source generator and inspect exactly what moved.

## Steps

1. **`npm run gen:all`** runs every generator. The list, its order and each generator's artifacts
   are `GENERATORS` in `scripts/check-drift.ts`; read it there, never from a copy here.

2. **Show the diff** over the artifacts `GENERATORS` names:

   ```bash
   git diff --stat
   ```

   Every changed path must be an artifact of some `GENERATORS` row.

   **Do not skim past `docs/cli-reference.md`.** It is generated from `src/manifest.ts`, so any
   CLI change at all (a new flag, a renamed one, a reworded example) lands there and nowhere
   else. It is the artifact that moves most often.

3. **If any artifact changed WITHOUT a corresponding source change, STOP and investigate.**
   Every generated byte must trace to an edit in a source of truth: the generator's own script
   under `scripts/` names the sources it reads. Two orderings matter and are set by the
   `GENERATORS` order: `gen:spec` before `gen:llms` before `gen:cli` (the CLI reference states the
   bundle size `gen:llms` measures).

   A diff with no matching source edit means either uncommitted drift you are about to fix, or a
   **nondeterministic generator**: chase it down, do not commit the mystery.

## Reminder

Never commit a hand-edit to a generated file. CI runs `check:drift` over every `GENERATORS`
artifact (`check:quick` runs it locally) and fails on any mismatch. Edit the source and regenerate.

> Note: `editors/language-configuration.json` is committed by hand, **not** generated.
