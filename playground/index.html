ArchLang Playground — write floor plans, compile them in your browser

ArchLang is an open-source (MIT) DSL for floor plans. Write .arch source (or open Source to edit this one) and it compiles in your browser to a dimensioned SVG plan — no install, no account. The same source also compiles to DXF, PDF and PNG from the command line.
