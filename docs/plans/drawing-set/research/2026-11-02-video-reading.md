# 视频精读：一份学校投标方案如何介绍建筑设计

记录日期 2026-11-02。材料是所有者提供的一段公开视频（B 站转码，1280×720，222 s），内容为“园中校园：佛山一中顺德学校建筑工程全过程设计国际招标竞赛方案”。本文只记录我们读到的结构和数字，不收录视频帧；视频和方案的权利属于其作者，不得作为 ArchLang 的宣传素材。

读取方式：每 4 秒抽一帧做接触表，再抽 720p 关键帧细读；用 `faster-whisper small` 转写，开启和关闭 VAD 各跑一次，只得到一条音乐幻听（`no_speech_prob` 0.79）。**结论：全片无旁白，信息全部在画面上。** “未见”一律指抽样范围内未见。

## 2. 专业之处

1. **每张图都有论点。** 岭南湿热气候 → 风压、热压通风 → 冷巷 → 架空与退台 → 剖透视里的风线和日照线，是一条因果链。
2. **尺度逐级下降再回到整体。** 城市 → 地块 → 组团 → 单体 → 构造层次 → 鸟瞰。
3. **同一底图反复分析。** 专项分析都用同一个场地轮廓，观众不必重新读图。这几张图几乎逐项对应《建筑工程设计文件编制深度规定》(2016) 2.3.1 第 7 项列出的分析图。
4. **颜色有语义。** 橙红是公共功能和连廊，绿是园林，灰是背景，章节编号贯穿全片。
5. **数字能闭合。** 我们核算过（见 §3）。
6. **动效表达生成过程。** 图层逐步叠加，线稿过渡到渲染图，动画本身解释设计逻辑。

## 3. 读到并核算的数字

- 任务书：非共享 80,099 m²，学生共享 35,928 m²，城市共享 45,337 m²。合计 161,364 m²，50% / 22% / 28%，与图上比例一致。
- 指标表（72 班高中 + 30 班初中）：用地 160,897.74 m²；总建筑面积 162,590.52 m²；计容 132,242.18 m²；地下车库及接送区 12,946.56 m²；架空层、风雨走廊 17,401.78 m²；容积率 0.82；建筑密度 40%；绿地率 35%；机动车位 132（含充电 34）；临时接送车位 138；非机动车位 432；最高建筑 55 m。
- 核算：132,242.18 + 12,946.56 + 17,401.78 = 162,590.52，完全相等；132,242.18 ÷ 160,897.74 = 0.8219，与 0.82 相符。
- 总平面比例尺约 135 像素 = 100 m。场地约 570×425 m，乘形状折减后与 16 公顷用地同量级。
- 建筑标注：教学楼 5F、H=21.2 m；教师宿舍 18F、H=57.3 m 和 9F、H=31.6 m；高中女生宿舍 9F；高中男生宿舍 16F、H≈59 m。

**疑似手工排版错误：** 宿舍 16F 的标注高度超过 18F，且都与“最高建筑 55 m”不一致。720p 下字迹模糊，这只是疑点，但正是派生数据能避免的错误类型。

## 4. 视频没有什么

抽样范围内未见带尺寸的标准层平面、门窗表、轴网尺寸链。平面信息只在分解轴测里出现。视频属于方案汇报层，ArchLang 现有强项（标注平面、明细表、校验）在它的下一层。两者互补，不是竞争。

基线 `main@18127701`，`dist` 1.50.0。
