## 5. 基线漂移（2026-11-02 落库时记）

本计划以 `main@18127701`（core 1.50.0）为基线。之后同一天发布了 core 1.51.0–1.53.0（`../preview-and-remodel/research/2026-11-02-as-built.md`），卡片正文未改，开工时按下表核对：

| 变化 | 影响的卡 |
|---|---|
| `spec.llm.md` 已到 29,972 单位（上限 `< 30_000`），不是 29,754 | DS1 要按现值腾出 ≥650，所有语言卡等它 |
| `sheet text { … }` 已发布（#403），表头和图上固定文字可由作者改写 | DS8 的表头改走 `sheet text` 的键，不再“等 #403” |
| Plan JSON 已携带墙的 `arc` 和 `paper` | DS6 的 `outdoor` 弧线要么进 Plan JSON，要么进 `dropped`，不能静默丢 |
| `axis.3` 读定位轴为坐标，`keep on axis` 支持柱子（J15） | DS12 导出 `axes` 时以此为准 |
| 楼梯 `bounds()` 已覆盖折断线（D27 关闭） | DS13、DS15 |
| 直角多边形房间有了“边”（J7）；房间可写 `floor` 填充，图签、指北针、比例尺可写 `hidden`（J14） | DS7、DS18 |
| DXF 已有 `BLOCK`、`INSERT`、`DIMENSION`（J12） | DS17 的 DXF 降级方案 |

卡片里的 `file:line` 都指 `18127701`，动手前重新确认。
