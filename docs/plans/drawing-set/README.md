# 方案图纸集计划：从平面图到一套能汇报的方案设计图

**状态：** 已规划，未开工。规划于 2026-11-02，基线 `main@18127701`（core 1.50.0）。本轮只有文档，没有实现。卡片在 `cards.md`，恢复点在 `handoff.md`，证据在 `research/`。

**一句话：** ArchLang 今天能画一张好平面。这个计划让一个 ArchLang 项目能产出中国方案设计阶段要求的一整套图：总平面、指标、平面、立面、剖面、分析图、图纸目录，所有数字都从模型派生，不靠手填。

**起因：** 所有者让我们分析一段学校投标方案视频，并思考如何让产出更专业、更可用（精读见 `research/2026-11-02-video-reading.md`）。没有开放 issue 要求剖面或立面，所以本计划不写“用户要求”，理由是 §1.1 的深度规定和所有者的 D29。

## 如何使用本文（给新会话）

1. 先读 `handoff.md`，确认当前位置和下一步。
2. 读 §1–§5，约十分钟。动某张卡前，读它引用的 `research/` 报告章节。
3. 选 `cards.md` 里依赖已完成、所在波次已开放的第一张 `todo` 卡。
4. 思考，不只是执行。证据与卡片矛盾时，修正卡片，在实施记录里写明原因，然后继续。不要为了变绿而祝福金样，也不要扩大卡片范围。
5. 法则照旧：`AGENTS.md`、`CLAUDE.md`、`docs/agents/*`。各卡的门禁见 `cards.md` §0。

## 1. 证据一页纸

### 1.1 验收标准来自规范，不是来自审美

《建筑工程设计文件编制深度规定》(2016) 的方案阶段清单，就是本计划的完成定义。来源是地方住建局转载的 `.doc`，不是部发原件，条款号以转载本为准。

| 条款 | 要求 | ArchLang 今天 | 负责卡片 |
|---|---|---|---|
| 2.1.2 | 封面、扉页、目录、说明书、图纸的顺序 | 单张 | DS19 |
| 2.2.1-7 | 用地、总建筑面积、基底、绿地、容积率、密度、绿地率、泊位、层数、层高、总高 | 只有地块面积和内净面积 | DS3、DS8、DS14 |
| 2.3.1-1…6 | 区位、场地范围、四邻、道路绿地建筑布置、建筑名称层数高度、指北针比例 | 部分 | DS6、DS7、DS14、DS18 |
| 2.3.1-7 | 分析图：功能分区、景观、交通、消防、地形、竖向、绿地、日照、分期 | 只有 `circulation` | DS16、DS17、DS21 |
| 2.3.2 平面 | 总尺寸、开间进深、柱网、房间名、标高、首层剖切线、指北针、比例 | 大部分已有，缺剖切线 | DS11 |
| 2.3.2 立面 | 代表性立面、标高、总高 | 无 | DS12–DS15 |
| 2.3.2 剖面 | 高度或层数变化处、各层标高、总高、编号、比例 | 无 | DS11–DS15 |

### 1.2 调研结论

**剖面和立面（`research/2026-11-02-section-elevation.md`）。** 语料 36 个示例、4807 个 shell 全部是竖直棱柱。所以隐藏线问题退化成“每个高度带解一次 1D 最近面包络”，即 Band Envelope 算法。我们不需要 OCCT 式通用隐藏线、三维布尔或新依赖。探针已入库于 `spike/`。主会话复跑结果：216 张图约 0.7 s，打乱输入 0 处字节差异，三角形射线预言机 32,400 样本 0 不符；四种注入故障都能变红。关键陷阱：斜面交叉不细化时，定向采样 139/400 错误，均匀采样却完全看不出。

**成熟工具的教训。** IfcOpenShell、Bonsai、FreeCAD 都靠 OCCT 加脆弱布尔，再做后处理补救；没有一个钉输出字节，也没有独立预言机。值得抄的是结构：投影在下、截面在上、注释最后，以及同类同材质才合并。代码全部不能用（LGPL、GPL、AGPL 或随机序）。

**真正的难点在 Scene3D 和图面规范，不在几何。** 楼梯没有几何（`stairOf` 丢弃 `flights`/`landings`），没有室外地坪，没有轴线，没有女儿墙。计划里的 `slab-below-floor` 规则没有实现，7 个示例的墙和板在剖切线上重叠。

**总图（`research/2026-11-02-repo-feasibility.md` §B，`research/2026-11-02-site-metrics-sun-standards.md` §1）。** IFC、Elements、CityJSON 都用“一份定义 + 引用处的变换”表达重复。ArchLang 不开新顶层形式，不放宽 `Frame`：`fromMatrix` 对非 D4 矩阵返回 `null`，`composeFrame` 会静默回退到恒等。任意角度只是把点算好写进多边形，渲染器不需要旋转。

**分析图和成套输出（`research/2026-11-02-views-and-sheet-sets.md`）。** 三件独立的小事：`diagram`（D2 的 scenario/step 语义）、`route`（默认不画的一等元素）、纯函数 `pack()`。关键字不能叫 `view`，它属于已废弃的轴测。

**标准。** GB 50099、GB 50016、GB/T 50947 读到的都是第三方副本，不是官方版。GB 7793-2025（2026-11-01 实施）据新闻新增“冬至日满窗日照时间”，原文未读。详见 §6。

### 1.3 勘误

- **上一轮对所有者的口头结论要更正。** 当时说剖面和标准层“适合赶在 Show HN 前完成”。标准层可以，剖面不行：它属于 `archlang-3d` 后续工作，D23、D29 让它等 N10 读数（不早于 2026-11-27），且 Show HN 保持 2D。
- 同一轮把 GB 50099 4.3.3（≥2 h）列为可直接用的条文。它可能被 GB 7793-2025 重新定义，已移出首批规则。
- 记忆里“法则修改除非所有者反对即生效”已过时。以 `docs/agents/iron-laws.md` 第 3–6 行和 plan-soundness D18 为准：可以落地，但标 *awaiting ratification*，所有者文字批准前不作先例。
- 交叉点数：报告写 64，主会话复跑是 72，输出线段都是 8956。报告的数字来自早期一轮，以复跑为准；两者都说明交叉只在含斜边的方案出现。
- 报告 02 §1.4 的 `building X = "file"` 语法，被报告 04 的两档设计取代（D4）。报告 03 §5.4 用的是 340×260 m 探针，真实场地是 570×425 m：A0 自动比例选 1:500 后报 `W_DRAWING_OVERFLOW`（实测），比报告的结论更支持扩展比例表（DS10）。

## 2. 原则

1. **图纸是模型的投影，文字数字也是。** 表、标注、图例都派生；作者不手填高度和面积。
2. **核心不画高度，这条不动。** 剖面和立面只在 `packages/archlang-3d`。核心可以画平面上的剖切符号，那是平面图元素。
3. **一个几何真相。** 剖面读 Mesh3D 同一批棱柱，不建第二份几何。
4. **底图不重排。** 一个 plan 的所有分析图，几何逐字相同，只追加图层。
5. **加法式语言。** 新形式都带字节恒等律；不用它的计划，SVG、`describe()`、`lint()`、`compile().diagnostics` 不动。
6. **精确或省略。** 算不准就省略并说明原因（ADR 0027 的立场），比如重叠地面不给绿地率。
7. **建议不是合规。** 画像和日照都是 advisory，不说“符合某标准”。指标不判限值。
8. **只读过的条文才能进规则。** 每个数字标 `[V]` 或 `[S]`（`docs/agents/iron-laws.md` 的 German-profile 原则）。
9. **预言机必须独立且会变红。** 剖面测试用原始三角形做射线，并用注入故障证明它有检测力。

## 5. 什么能证明本计划错了

- **Band Envelope 的棱柱假设被打破：** 楼梯落地后，非棱柱几何让 T1 无法收窄。对策是横向棱柱（`research/2026-11-02-section-elevation.md` §5）；若还不行，停下重估。
- **图面没人买账：** DS13 完成后请一位建筑师看图。如果判定“不像方案图”，几何对也不算完成。
- **语言预算撑不住：** DS1 削不出 650 字符。不许调阈值，只能砍卡。
- **没有外部使用：** 波次 3 发布后 4 周内，没有任何外部方案使用 `section` 或 `elevation`，暂停波次 4，重新问价值。
- **加法式失败：** 任一卡字节恒等律无法成立且无法用 opt-in 解决，该卡作废。

## 7. 验收方案

`examples/` 新增一份虚构校园（不复制视频方案）：约 16 公顷斜边地块，教学楼、宿舍、体育馆、400 m 跑道，全中文。程序完成的定义：

1. `archlang pack` 一条命令产出：目录、总平面、指标表、各层平面、4 向立面、至少 2 张剖面、至少 4 张分析图的多页 PDF。
2. 指标表每个数字可由 `describe --facts indicators --json` 复算。
3. 两次运行字节相同；Linux、Windows CI 比对同一 SHA。
4. `validate --strict` 通过；`cn-school-advisory` 的警告都有意义。
5. 故意把宿舍改到 19 层，指标、标注、立面、剖面同时变化，无手改。这条就是对视频里疑似错误的回答。
