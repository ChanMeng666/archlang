### As built

Built by the main session (PR #325, merge `88d83823`). `packages/archlang-3d`: private,
`engines.node >=20`, MIT; `adaptPlan(source, { world })` → Scene3D v0 in integer micrometres or a
named refusal (`E3D_PLAN_ERRORS`, `E3D_NO_WALLS`, `E3D_CORE_TOO_OLD` by feature-detecting
`resolvePlan`). Walls are each wall's owned region from `joinWallSet`'s split (H1), one polygon per
connected piece, openings not removed (each opening carries its `cut`). Types,
`scene3d.schema.json` and a zero-dependency validator held to the same verdicts. `src/node.ts` holds
the Node `World`. `scripts/planjson-gap.mts` is the spike's script with the Windows `import()` fixed
(13 of 34 examples still need more than Plan JSON). ADR 0030 promoted (Accepted) with the v0.7
exposure tiers; the workspace joined `typecheck:all`; root `check:3d` runs `e2e/*.e2e.ts` (empty,
green); a `docs/backlog.md` programmes row.

Acceptance as measured: all 34 examples adapt and validate; each storey's openings equal the
joinery's cuts and every other collection equals the core's element counts. H1 on s1…s11 and the
corpus (290 walls): exact tiling on straight walls, ≤ 4.8e-4 with arcs; no empty owner; every cut
on a piece. The orientation convention (`yaw = −rotate`, front faces page-down at 0) holds on
laneway-house's six against-wall pieces and fails under the flipped sign. The schema and the
validator agree on the corpus and 11 plants. The browser bundle (core inside) carries no static
`node:` import, `process`, `Date.now`, `new Date`, `performance.now` or `Math.random`.

Gates: package suite 13 s (75 tests); `check` 576 s against the 557 s baseline (+3.4 %, inside the
card's 10 %); `check:drift` 26 s; `docs:build` 44 s; `check:3d` 2 s; `typecheck:all` 57 s; CI's
Node 18 leg green (the light tests need no skip).

Corrections to the card, recorded in the PR: Scene3D lengths are micrometres, not millimetres;
"zero externals" holds for the resolver path only, so the test externalises exactly the core's own
`NODE_ONLY` list (read from `packages/web-component/scripts/build.ts`) and proves the build fails
without it; the mixed-height rule is decided by ownership (the lower wall owns part of the taller
wall's band), so it fires on `s11` only and never on a butt joint, matching A2's acceptance (plan
§4.1's "touching, unequal heights" would also fire on `s4`); wall footprints keep their openings
(H1 rule ②); no watertight prism check yet (triangulation is A2's); a height's provenance is not
recorded (only private IR fields carry it). Independent red-team round 1: 2 major, 4 minor, all
fixed; a CodeQL `js/incomplete-sanitization` in the browser test was fixed by dropping the regex.

Left (cards): the core does not export the hatch group key `joinWallSet` groups fills by (the
