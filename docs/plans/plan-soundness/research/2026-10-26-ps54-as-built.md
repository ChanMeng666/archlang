Record for card PS5.4: `arch preview --review`, the review sheet. Branch `feat/preview-review-ps54`.

## What shipped

- **`arch preview <file> --review [-o out.png] [--width] [--scale] [--level] [--json]`.** One PNG:
  1. the plan exactly as `preview` draws it (the default `compile()` SVG, embedded byte for byte);
  2. the access graph from `describe().access` for the storey: each room a node at its label point
     (`roomLabelAnchor`, so from the shape), filled when reachable from an entrance on this storey and
     hollow when not; one edge per door or opening, drawn from each room's node through the connector;
     ambiguous connectors dashed grey; entrances marked;
  3. every element a warning names ringed, with a numbered badge and the code (without `W_`) beside it;
  4. a legend: number, code and the message exactly as `lint` prints it (id-free); a warning that
     names nothing drawn on the storey is listed with "(not on the drawing)";
  5. a strip of close-ups, one tile per flagged door, window, opening or furniture piece, each titled
     with its numbers and codes.
- **`--json`** adds `review: true`, `rings` (how many marks are ringed), `marks[]` (`n`, `code`,
  `message`, `channel`, `element: { id, kind } | null`, `ring` box in plan mm) and `crops[]` (`n[]`,
  `element`, `box` in plan mm). Ids appear in the JSON, which an agent edits by, never in the legend.
- **Teaching.** Manifest flag and example (regenerated into `docs/cli-reference.md`, `llms-full.txt`);
  one sentence in SKILL step 7's review paragraph (and the plugin copy); README §4's reviewer-tools
  line. `spec.llm.md` is untouched: its CLI list carries command summaries only, and `preview`'s
  summary did not change. Context size unchanged (`src/context-size.ts` did not move).

## Decisions

- **Where it lives: the CLI layer.** The composition reads `compile()` (twice: once plain for the
  drawing, once `annotate`d for each element's drawn nodes), `resolvePlan()` (element spans and
  shapes), `describe()` (the access graph) and `lint()`; it feeds none of them. It is pure apart from
  that (no I/O, time or randomness), so the SVG is deterministic and pinned by hash.
- **Which warnings.** `compile()`'s warnings plus the default-ruleset `lint()`'s, for the storey
  drawn (a diagnostic with no `level` shows on every storey), each once. The dedupe key is code,
  message, hints, span and level: the hints are in it because two placed instances of one component
  raise the same message from one span and only the hint's ids tell them apart. Numbered in source
  order of the span (no span last), then code.
- **Span to element.** The narrowest resolved element whose statement contains the diagnostic's span
  (the rule `impact` keys by). On a tie (one component placed several times), the element whose id a
  hint quotes; else, when a hint quotes a door, window or opening, the tied room nearest that
  connector (inside or by distance to the floor outline); else the first. On `hillside-villa` level
  2 this places the three ensuite `W_PATH_TOO_NARROW` marks on `en2.room`, `en3.room` and
  `en_m.room` (before the hint rule all three landed on `en2.room`).
- **Ring shapes.** A room: its floor outline (polygon, circle or rectangle), a translucent band plus a
  dashed line, its tag lifted above its label point. A wall: its centreline at its thickness. A door,
  window or opening: a circle about its centre, radius half its width plus a pad. Anything else
  (furniture, column, stair …): a rounded rectangle around every point its own scene nodes draw. That
  last is a drawing annotation enclosing drawn ink, not a derived position, so the shape law is not
  engaged. The pad is 1/120 of the page's longer side.
- **What is cropped.** Doors, windows, openings and furniture (the card's "junction / opening /
  clearance"); rooms and walls are ringed but not cropped. One tile per element, not per warning.
- **Fixed scale.** Every tile is 0.25 sheet units per mm (1 m = 250 units on a 1,600-unit-wide sheet,
  scaled to `--width`), at least 2,400 mm square and the element's extent plus 600 mm each side,
  capped at the sheet's inner width. Tiles flow left to right and wrap.
- **Default output** `<name>.review.png`, so it never overwrites the plain preview.
- **Refusals.** `--review` with `--ascii`, `--view` or `--overlay` exits 3 (the sheet is a PNG of the
  plan with its own overlay). A broken plan takes `preview`'s own failure path (exit 2; with
  `--error-svg`, the error card), handed the source already read so stdin is not read twice.
- **Multi-storey.** One sheet per storey, chosen with `--level` exactly as `preview` does (default the
  lowest).

## Open

- Tags can collide where flagged elements sit close together (the badges of adjacent rooms); a
  placement pass like the label one is a follow-up if reviewers find it hard to read.
- The access graph of an upper storey shows every room hollow: `describe().access` reads each storey
  from its own entrances, and an upper storey has none. The drawing reports the fact as `describe()`
  states it; a stair-aware reading is a `describe()` question, not a drawing one.
