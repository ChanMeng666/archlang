## The double-report rule

`W_DOORWAY_BLOCKED` owns the doorway's own landing (300 mm; 450 under the a11y profile). A piece
whose footprint overlaps that landing is the sibling's report and is never named by this code, so one
sofa is reported once. It still counts toward the clear width, so the width another, deeper piece is
said to leave is the width really left. If every piece in the strip is in the landing, this code is
silent.

## Sources

- Default 914 mm: International Residential Code R311.3, "a landing or floor on each side of each
  exterior door", not less than the door served and "not less than 36 inches (914 mm) measured in
  the direction of travel". **Second-hand [S]**: the 2012 and 2021 text as quoted in Indiana DHS's
  copy (`2026-10-27-ps267-271-sources.md` § PS2.69). The ICC public viewer (codes.iccsafe.org, IRC
  2021 chapter 3) returned HTTP 403 on 2026-10-27, and a search found only state copies and forum
  transcriptions, so the figure is not marked as read. The message therefore says "clear floor a way
  out needs" and only the hint carries the citation.
- `accessibility-advisory` 1220 / 1525 mm: the 2010 ADA Standards, 404.2.4.1 and Table 404.2.4.1,
  front approach: push side 48 in, pull side 60 in, perpendicular to the doorway [V, a transcription
  of the Standards]. The 18 in / 12 in beyond the latch side is not modelled.
- Not applied: IBC 1010.1.6's 44 in (1118 mm) outside dwellings (optional in the record).
