# PS7.2 as built: `archlang context --level starter`

Dated 2026-10-26 (branch `feat/context-starter-ps72`). The card: a one-screen starter for weak models,
the same truth as the full context, less of it.

## What shipped

- `archlang context --level starter` prints one screen: 3,673 UTF-16 units (3,677 bytes), cap
  `STARTER_MAX_UNITS` = 4,000, pinned by test. Sections: the lead example, the six statements a plan
  needs, the loop, the five errors cold authors hit first, and the pointers to `explain`, `spec` and
  `context`.
- `--level full` is the default and the same output as before (the whole bundle). `--level <other>` is a
  usage error with a did-you-mean; `--level starter --section <name>` is a usage error (a section picks a
  part of the full bundle). `--json` gives `{ ok, level: "starter", context }`.
- `--level` already means a storey number on `compile|preview|describe`. The parse table
  (`FLAG_KEYS`) gained an optional `perCommand` override, so `context` reads `--level` as a string into
  `Args.contextLevel`; every other command still reads a number into `level` (a test runs
  `describe --level starter` to show it is still refused as a number).
- Code: `src/cli/context-starter.ts` (pure renderer plus the error table), `cmdContext` in
  `src/cli/commands-meta.ts`, the manifest flag, `test/context-starter.test.ts` (31 cases).
- Teaching: one clause in `skills/archlang/SKILL.md` step 1 (a small model starts with the starter), a
  line in `docs/overview.md`; the generated copies follow `gen:all` (`docs/cli-reference.md`,
  `llms-full.txt`, the plugin SKILL copy).

## Decisions

1. **Runtime from the same source, no new generated file.** The starter is rendered at run time from the
   shipped `spec.llm.md`: the lead example is the spec's first ```arch fence, which
   `test/spec-forms.test.ts` already pins equal to `LEAD_EXAMPLE`; `test/context-starter.test.ts` pins
   the extraction to `LEAD_EXAMPLE` again. `LEAD_EXAMPLE` lives in `scripts/`, which the package does not
   ship, and moving it to `src/` would have touched `scripts/gen-llm-spec.ts` (PS7.1's file). The
   extraction touches no generator.
2. **Statements are lines of the example.** Six statements are taught from eight lines of the lead
   example picked by their first words (`STARTER_PICKS`); the room line has `label "Living"` inserted
   before `uses` (the clause order the audits show cold authors get wrong), and a test compiles and lints
   the lead plan with that line. The relational directions are `REL_DIRS`. The one line the example does
   not carry, `furniture tv_unit against living.top`, is compiled and linted inside the lead plan (0
   diagnostics). `wardrobe against bedroom.top` was tried and fires four warnings, so it is not used.
3. **The error table is executable.** Each of the five rows (`E_PARSE` label/uses, `E_FURN_SIZE`,
   `E_OPENING_DATUM`, `E_OPENING_NIB`, `E_FURN_AGAINST`) has a `bad` statement that raises exactly that
   code and a `good` one that compiles with no error, both run in a probe plan by the test. The fix
   sentences are authored (the catalogue's `fix` for `E_PARSE` and `E_FURN_AGAINST` is a paragraph, and
   for `E_FURN_SIZE` it omits the `anchor` case that is the actual trap); the row's code, its bad and
   good statements are what the compiler confirms. The five codes come from the first-contact audits'
   authoring-friction lists (`E_FURN_SIZE` ×18 in one run, `uses` before `label` ×13 twice).
4. **No MCP change.** The MCP `context` tool is noted only (card PS5.3a).
5. **Not a taste step.** The loop says `score --taste` is the reviewer's tool (D20).

## Evidence

- Starter: 3,673 units. Every snippet in it is a test case; 31 of 31 pass.
- `context` (default) equals the committed `llms-full.txt` byte for byte; `context --level full` equals
  `context`.
- Corpus: nothing in `compile()`, `describe()`, `lint()` or the SVG changed; no example edited.

## For the next re-measure

This is a surface for small models. Whether a weak author uses it is not measured here; the thing to
watch is whether an author told to run `archlang context --level starter` writes `label` before `uses`
and puts a `size` on every `in … anchor` furniture line.
