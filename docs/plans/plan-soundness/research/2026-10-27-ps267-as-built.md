- `src/lint/rules/footprint.ts` (`bedUndersized`, beside `W_FOOTPRINT_TRANSPOSED`), appended last to
  `LINT_RULES`; classified `invariant` in `test/d4-oracle.ts` (two side lengths).
- The longer side is the length however `size` and `rotate` are written: a bed across its own length is
  `W_FOOTPRINT_TRANSPOSED`'s finding. One diagnostic per bed, the length and width findings joined.
- The message names the room, never an assigned id (ADR 0029 §6), and names Which? only when the figure
  is the default. No profile sets either field (the profile blocks admit [V]/[S] figures only); a caller
  may override through `ruleset`.
- No machine fix: lengthening a bed moves it into what it was cut to clear.
- Reverse-if: a normative standard (BS, EN, GB/T 3328-2016's size table) read with a different minimum
  replaces the figures, as a profile value where national.
