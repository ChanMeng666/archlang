**Latest release: v1.36.0 (2026-09-13)** — *"a compiled plan you can reach with a keyboard"*, a
MINOR, and the first release driven by a downstream consumer's accessibility work rather than by the
language. It **adds no language surface**: no keyword, no grammar token, no schema field — `spec.llm.md`,
`grammars/archlang.gbnf` and both `schemas/*.json` are byte-unmoved, which is why the VS Code bundle
one minor behind is not stale. What moved is the SVG under two existing opt-ins. `annotate` now also
stamps **`data-arch-label`** (what the plan CALLS the element — the authored `label`, else the
catalogue word, verbatim; **absent** for every `door`/`window`/`opening`, which the language names
nothing) and **`data-arch-primary`** (empty, on **exactly one node per `data-arch-id`** — the
element's first non-`text` primitive). With `accessible` beside it, that primary becomes a control:
`role="button"`, `tabindex="-1"` always, and an `aria-label` that leads with the kind
(`Room Kitchen`, `Furniture Bed, Kitchen`, `Door`; an unnamed room takes a dense ordinal, `Room 1`),
while every non-primary `<text>` goes `aria-hidden`. `accessible` also takes `{ idPrefix }` (CLI
`--acc-id-prefix`) so several plans in one HTML page do not share `arch-title`/`arch-desc`. **The
`<svg>` root keeps `role="img"`** — a drawing is one image until a consumer makes it something else,
and what a consumer still owns (the roving tab stop, `aria-pressed`, focus, and taking `role` and
`tabindex` back OFF for a read-only render) is documented in `docs/language-reference.md`. Also
fixed there: `annotate` spliced its attributes with a `String.replace` **replacement string**, so a
label containing `$&` or `$'` could splice markup back into its own attribute — unreachable in every
released version, because `data-arch-label` is the first stamped value that can be arbitrary author
text; now a function replacement, found by `test/escape-fuzz.test.ts`. Full account in
`CHANGELOG.md`; the consumer contract and the **known screen-reader limitations** (what is still
unnamed, and why each is a consumer's problem today) are in `docs/language-reference.md`, with the
upstream items in `docs/backlog.md` § "A11y of the compiled drawing". Shipped alongside **MCP shim
0.2.16**; **VS Code 0.24.0** is live and unchanged by this release.
